# QuizUp — Interactive Quiz App

Aplikasi kuis interaktif berbasis HTML, CSS, dan JavaScript murni.

## Fitur
- 5 soal pilihan ganda dengan urutan acak
- Render soal menggunakan `createElement()` dan `textContent`
- Event delegation untuk pilihan jawaban
- Skor otomatis dan high score melalui `localStorage`
- SPA tanpa reload halaman
- Feedback visual benar/salah
- Timer 15 detik per soal
- Progress bar, dark mode, dan tombol restart

## Menjalankan
Buka `index.html` di browser. Tidak membutuhkan instalasi atau API key.
